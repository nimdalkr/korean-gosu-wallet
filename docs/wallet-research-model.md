# 지갑 리서치 모델

KGW의 지갑 리서치 데스크는 각 주소를 단순 거래 건수가 아니라 **행동 주체**로 읽기 위한 조사 보조 모델입니다. 최근 30일 공개 온체인 기록을 지갑별로 재구성하고, 최근 7일의 변화와 코호트 공통 관심사를 함께 보여줍니다. 모든 점수는 수익률 예측이나 실소유자 판정이 아니라 원문을 먼저 확인할 순서를 정하는 휴리스틱입니다.

## 분석 단위

- 지갑 프로필: 406개 추적 주소마다 1개를 생성합니다.
- 최근 구간: 생성 시각 직전 7일입니다.
- 비교 기준선: 그보다 앞선 23일의 일평균입니다.
- 코호트: 업비트 또는 빗썸 QUID 입금 발신 주소군입니다.
- 원문 근거: 일반 트랜잭션, internal transaction, ERC-20·721·1155 transfer와 BaseScan 링크입니다.

QUID 입금은 코호트를 선별한 사건이므로 투자 성향, 관심 자산, 의미 행동, 알파 테마 점수에서 제외합니다. 지갑 상세의 자산 이동 장부에서는 추적 배경 확인을 위해 남을 수 있습니다.

## 지갑별 리포트

각 지갑 리포트에는 다음 항목이 포함됩니다.

| 항목 | 의미 |
| --- | --- |
| 애널리스트 뷰 | 30일 의미 행동, 직접 서명, 주력 관심, 현재 운용 태도를 한 문단으로 요약 |
| 최근 변화 | 최근 7일 의미 행동을 이전 23일 일평균과 비교 |
| 운용 유형 | 능동 트레이더, 토큰 운용·정리형, DeFi 운용자, 프로토콜 탐색자, NFT 컬렉터, 에어드롭·클레임형, 축적형, 분배형, 거래소 송금형, 멀티전략, 수동 보유·활동 미확인형 중 하나 |
| 행동 구성 | QUID·스팸을 제외한 활동 유형별 30일·7일 건수, 전체 비중과 지갑 직접 실행 수 |
| 관심 지문 | 자산·NFT·프로토콜·섹터별 활동 강도와 직접 행동 수 |
| 자산 장부 | 30일 수신·전송·순수량, 7일 건수, 직접 행동, 가격 확인 가능한 순 USD |
| 프로토콜 지도 | 지갑이 직접 호출한 컨트랙트, 메서드, 최초·최근 접근 |
| 상대방 지도 | 거래소, 추적 코호트, 컨트랙트, 외부 주소별 반복 상호작용 |
| 중요 흔적 | 최신성·직접성·행동 종류·연관 신호를 합친 상위 트랜잭션과 해석 |
| 다음 확인 포인트 | 다음 수집 구간에서 검증해야 할 후속 행동 |

운용 유형은 서로 배타적인 확정 신분이 아닙니다. 최근 30일의 우세 패턴을 빠르게 읽기 위한 대표 라벨이며, 보조 태그와 원문 흔적을 같이 봐야 합니다.

## 핵심 점수

### Research Priority

0~100점 조사 우선순위입니다. 노이즈가 아닌 최고 신호 점수, 최근 7일 신호 수, Agency, Depth, 활동 가속도, QUID 입금 Top 100 여부를 합산합니다. 수동 수신형에는 감점을 적용합니다.

- 80 이상: 즉시 원문 확인
- 70~79: 우선 조사
- 50~69: 관찰
- 49 이하: 낮은 우선순위

### Agency

0~100점으로, 주소가 외부에서 토큰을 받은 것보다 **직접 서명해 행동한 정도**를 나타냅니다. 직접 시작한 활동 비율, 정상 outbound transaction 수, 의미 행동과 메서드 다양성을 반영하고 스팸 비중을 감점합니다.

### Depth

0~100점 운용 깊이입니다. 직접 프로토콜 수, 매수·매도 추정·민팅·브리지·스테이킹·유동성 같은 고차 행동, 직접 다룬 자산 수와 한 트랜잭션의 복합 행동을 반영합니다.

### Evidence Confidence

- HIGH: 서로 다른 근거 트랜잭션 12개 이상이면서 직접 outbound transaction 5개 이상
- MEDIUM: 근거 4개 이상 또는 직접 outbound transaction 2개 이상
- LOW: 그 미만

Confidence는 결론의 진실 확률이 아니라 프로필을 지지하는 공개 체인 근거의 양입니다.

## 최근 변화와 운용 태도

`Momentum`은 최근 7일 일평균을 이전 23일 일평균과 비교합니다.

- 급증: 2배 이상이며 최근 의미 행동 3건 이상
- 확대: 1.25배 이상
- 유지: 0.55배 초과 1.25배 미만
- 둔화: 0.55배 이하
- 비활성: 최근 7일 의미 행동 없음

`Stance`는 최근 7일의 비QUID·비스팸 흐름을 순유입, 순유출, 회전, 신규 프로토콜 탐색, 관찰, 비활성으로 요약합니다. 이는 잔고나 실제 포지션을 뜻하지 않고 관찰 구간의 transfer 방향을 뜻합니다.

## 코호트 알파 테마

자산·프로토콜·섹터별로 최근 7일에 여러 지갑이 어디로 수렴하는지 계산합니다. 점수에는 참여 지갑 수, 직접 행동 지갑 수, 거래소별 Top 100 참여, 업비트·빗썸 교차, 이전 23일 대비 가속도와 유입·유출 방향이 들어갑니다.

다음 조건은 수동 배포형 노이즈로 분리합니다.

- 최근 7일 3개 이상 지갑에 수신됨
- 유입 3건 이상
- 단일 발신자 또는 동일 수량 집중도 75% 이상
- 직접 행동이 없는 지갑 비중 70% 이상

이 조건에 해당하는 자산은 개별 지갑의 페르소나·관심 섹터·행동 구성·Agency 계산에서 제외합니다. 다만 실제 수신 흔적을 감추지 않도록 상세 자산 장부에는 `수동 배포`로 표시해 남깁니다.

테마의 `직접 행동 지갑`은 해당 주소가 outbound transfer를 만들었거나 같은 트랜잭션을 직접 시작한 경우입니다. 단순 수신 지갑 수와 구분합니다.

## 해석 원칙

- 토큰 수신은 매수가 아닙니다. 결제자산 유출이 같은 트랜잭션에서 확인될 때만 매수 후보로 분류합니다.
- 토큰 전송은 매도가 아닙니다. 결제자산 유입이 함께 확인되거나 알려진 거래소 목적지가 확인돼야 해석 강도가 올라갑니다.
- 컨트랙트 호출은 관심의 근거일 수 있지만 투자 의도나 향후 가격 방향을 보장하지 않습니다.
- 섹터는 토큰·컨트랙트 이름을 이용한 규칙형 분류이므로 프로젝트 공식 분류와 다를 수 있습니다.
- USD 값은 Blockscout가 가격 메타데이터를 제공한 ERC-20 transfer만 계산합니다. 화면의 가격 커버리지가 낮으면 수량과 원문을 우선합니다.
- 주소는 실사용자와 일대일 대응하지 않습니다. 공통 자금원·동일 자동화·실소유자 연계는 별도 클러스터링 근거가 있어야 합니다.
